# НейроКафе · прототип социальной сети

Откройте `index.html` в браузере. Прототип статический и не требует сборки.

Что внутри:

- лента сообщества с дневной целью;
- создание публикации;
- комментарий и репост как действия, которые засчитываются в серию;
- вкладки пользовательского телефона: `Лента`, `Челленджи`, `Друзья`;
- success/error/empty states для отклика, закрытия дня и пустых друзей;
- запусковые тексты для письма, баннера и push вынесены из телефона в отдельный handoff-блок;
- UX-аудит и приоритеты доработки справа от экрана приложения.

Связанный документ: `UX_RECOMMENDATIONS.md`.

Материалы этапа 2:

- `STAGE_2_UX_SOLUTIONS.md` - UX-решения, сценарии улучшений и приоритеты прототипирования;
- `STAGE_2_UX_REVIEW.md` - проверка этапа 2 по ТЗ, приоритетные правки перед согласованием;
- `stage2.html` - презентационная страница этапа 2;
- `figma-plugin-neurocafe-native-proposal` - локальный Figma-плагин для создания native proposal в Design Mode: мобильные экраны, обязательные состояния, desktop handoff и launch-блок отдельно от user UI;
- `skills/neurocafe-ux-reviewer` - проверяющий для UX/UI, запуска и соответствия ТЗ.

Изображения бейджей лежат в `assets/icons`, поэтому прототип можно открыть из репозитория без локальных внешних папок.
